# Documentation images

Put screenshots intended for the public README here. Use descriptive names,
such as `djay-crossfader-thru-warning.png`, rather than capture timestamps.
PNG is suitable for app windows and text.

Before adding screenshots, crop out unrelated windows, personal file paths,
account details, and private library content. Keep the relevant message and
enough surrounding UI to explain it.

Link from the root README with:

```markdown
![Djay's expected crossfader assignment warning for THRU](docs/images/djay-crossfader-thru-warning.png)
```

Current images:

- `djay-crossfader-thru-indicator.png`: Djay's expected warning triangle.
- `djay-crossfader-thru-warning.png`: the assignment-change dialog; choose
  Keep to retain the hardware switch assignments.
- `bridge-settings.png`: cropped from local native QA evidence to show bridge
  controls and mapping installation without the private preferences path.
- `jog-settings.png`: native QA evidence with example custom values, not the
  beta's default values.

Original QA captures remain in `.omo/evidence/`; publish only selected,
reader-facing copies here.
